# Xzense 0.5.28.9

## English

### Fix: Repeated automatic discovery of an already configured Xzense panel

Home Assistant could repeatedly suggest **Xzense (A809)** as a new integration although one panel was already configured, because discovered Bluetooth advertisements used different MAC addresses.

- Automatic Bluetooth discovery now compares **both the advertised name and MAC address** against already configured Xzense entries.
- Panel names are compared without case sensitivity and with normalized whitespace. The saved original device name is used, not a Home Assistant custom entry title.
- When a matching configured device exists, the automatic flow aborts as `already_configured` before offering setup. The confirmation step checks again before saving.
- **Manual setup by Bluetooth address and PIN remains supported**, including intentionally configuring multiple real panels with identical names. Different device names remain independently discoverable.
- The existing BLE communication, proxy selection, controls and entity IDs are unchanged.
- Regression tests cover distinct discovered MACs with the same name, same MAC, legitimate distinct panels, manual configuration and automatic flow behavior.

**Note:** Matching names are a pragmatic heuristic, not proof that the addresses represent the same hardware. This release does not change or erase previously configured entries. On-device confirmation is still needed to establish whether the repeated suggestions disappear.

## Norsk

### Rettet: Gjentatt automatisk oppdagelse av allerede konfigurert Xzense-panel

Home Assistant kunne stadig foreslå **Xzense (A809)** som en ny integrasjon selv om ett panel allerede var konfigurert, fordi nye Bluetooth-annonser hadde andre MAC-adresser.

- Automatisk Bluetooth-oppdagelse sammenligner nå **både annonsert navn og MAC-adresse** med allerede konfigurerte Xzense-oppføringer.
- Navn sammenlignes uten forskjell på store og små bokstaver, og overflødige mellomrom ignoreres. Sammenligningen bruker det opprinnelig lagrede panelnavnet, ikke et egendefinert navn i Home Assistant.
- Hvis et tilsvarende panel finnes, avbrytes automatisk oppdagelse med `already_configured`. Det gjøres også en ekstra kontroll før PIN-bekreftelsen lagrer oppføringen.
- **Manuell registrering med Bluetooth-adresse og PIN beholdes**, også hvis man faktisk har flere paneler med identisk navn. Andre panelnavn kan oppdages normalt.
- Ingen endringer i eksisterende Bluetooth-kommunikasjon, proxyvalg, kontroller eller entitets-ID-er.
- Regresjonstester dekker samme navn med ulik MAC, samme MAC, andre ekte paneler, manuell registrering og automatisk oppsett.

**Merk:** Navnelikhet er en praktisk antakelse, ikke et bevis for at adressene tilhører samme fysiske panel. Versjonen endrer eller sletter ikke eksisterende oppføringer. Vi må bekrefte på fysisk anlegg at forslagene faktisk forsvinner.
