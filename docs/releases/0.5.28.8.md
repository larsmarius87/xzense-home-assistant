# Xzense 0.5.28.8

## English

### Revert: Fan-speed write interlock introduced in 0.5.28.7

This release **reverts only** the Boost-related GLOBAL `0x50` write guard introduced in version 0.5.28.7.

- Writing the normal fan-speed setting (`0x50`) now behaves as it did in **0.5.28.6**; the integration no longer forces an extra status request or blocks `0x50` solely because Boost (state 3) is active.
- The user observed unchanged behavior after 0.5.28.7. A potential explanation is the Xzense controller's own Boost-stop temperature setting (`0x52`, reportedly 60 °C) while the chimney temperature was about 140 °C. This explanation is **not yet confirmed**.
- The independent Boost control (`0x08`) and all other Bluetooth control logic remain unchanged.
- Fixes from 0.5.28.6 and earlier, including stricter Bluetooth device discovery and dashboard button handling, are retained.
- The bundled card version is updated to **0.5.28.8**.

**Validation:** Automated build and rollback checks. Whether the controller terminates Boost due to the temperature limit remains to be verified on hardware.

## Norsk

### Tilbakeført: Skrivesperren for viftehastighet fra 0.5.28.7

Denne versjonen **tilbakefører kun** sperren for GLOBAL `0x50` som ble innført i 0.5.28.7.

- Skriving til normal viftehastighet (`0x50`) fungerer igjen som i **0.5.28.6**. Integrasjonen krever ikke lenger en ekstra statusforespørsel eller sperrer `0x50` bare fordi Boost (tilstand 3) er aktiv.
- Brukeren observerte uendret oppførsel etter 0.5.28.7. En mulig forklaring er panelets egen Boost-stopptemperatur (`0x52`, oppgitt til 60 °C), samtidig som pipetemperaturen var omtrent 140 °C. Dette er **ikke bekreftet**.
- Den separate Boost-kommandoen (`0x08`) og resten av Bluetooth-styringen er uendret.
- Rettelsene fra 0.5.28.6 og tidligere, inkludert strengere Bluetooth-oppdagelse og dashboardknapper, er beholdt.
- Dashboardkortet viser **0.5.28.8**.

**Verifikasjon:** Automatiske bygge- og tilbakeføringstester. Det gjenstår å bekrefte på det fysiske panelet om temperaturgrensen avslutter Boost.
