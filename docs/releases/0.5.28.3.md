# Xzense 0.5.28.3

## English

**Fix:** The bundled Xzense dashboard card now allows **Start firing**, **Refuel**, and **Stop firing** buttons to be pressed even when Home Assistant reports the button's state as `unknown`. Home Assistant's button entities can legitimately have that state before being pressed.

- Buttons that are `unavailable` or not registered remain disabled.
- Non-button sensors and controls still reject an `unknown` state.
- Automatic entity discovery, manual overrides, and multi-device selection are retained.
- No changes to Bluetooth communication, controller commands, or Home Assistant service handlers.
- Battery percentages are still capped at 100% in Home Assistant while the original GLOBAL `0x04` remains available in diagnostics.

**Version:** `0.5.28.3` · **Domain:** `xzense` · **Distribution:** HACS GitHub Release.

**Note:** The dashboard card must already be registered as a Lovelace resource. Refresh the browser after updating if the older JavaScript remains cached.

## Norsk

**Rettet:** Xzense-dashboardkortet lar nå knappene **Start fyring**, **Legg inn ved** og **Avslutt fyring** trykkes selv om Home Assistant rapporterer knappens tilstand som `unknown`. Denne tilstanden er normal for knappentiteter før de har vært brukt.

- Knapper som er `unavailable` eller ikke registrert, holdes fortsatt deaktivert.
- Sensorer og andre kontroller med tilstanden `unknown` behandles som før.
- Automatisk entitetskobling, manuell overstyring og valg mellom flere Xzense-enheter beholdes.
- Ingen endringer i Bluetooth-kommunikasjonen, kommandoene til kontrollpanelet eller integrasjonens styringslogikk.
- Batterisensoren begrenses fortsatt til 100 %, mens råverdien fra GLOBAL `0x04` beholdes i diagnostikken.

**Versjon:** `0.5.28.3` · **Domene:** `xzense` · **Distribusjon:** GitHub Release for HACS.

**Merk:** Dashboardkortet må allerede være registrert som Lovelace-ressurs. Oppdater nettleseren hvis gammelt JavaScript fortsatt ligger i hurtigbufferen.
