# Xzense 0.5.28.6

## English

### Fixed: Unrelated Bluetooth devices suggested as Xzense

Home Assistant could previously offer unrelated Bluetooth devices as Xzense controllers because the integration registered a shared Dialog/Renesas DSPS service UUID for automatic discovery.

- Automatic Bluetooth discovery now matches the advertised **Xzense-prefixed device name** (`Xzense*`) instead of the shared DSPS UUID.
- The config flow uses the same name-based filter, including when listing nearby discovered devices for manual selection.
- The existing manual setup option for Bluetooth address and PIN remains available, including for a legitimate controller not advertising its name.
- Regression tests cover known Xzense name variants and reject unnamed and unrelated devices even when they advertise the DSPS UUID.
- No changes to Bluetooth connections, polling, proxy selection, controller commands, or safety gating.
- The bundled dashboard card displays version **0.5.28.6**.

### Known limitation

Automatic discovery requires the Bluetooth advertisement name to begin with `Xzense`. Devices using a different name or not broadcasting a name must be configured manually. Existing configuration entries are not removed.

**Verification:** Automated build and regression tests. Not yet confirmed against every Xzense hardware variant.

## Norsk

### Rettet: Andre Bluetooth-enheter foreslått som Xzense

Home Assistant kunne tidligere foreslå andre Bluetooth-enheter som Xzense-kontrollere fordi integrasjonen brukte en delt Dialog/Renesas DSPS-tjeneste-UUID ved automatisk oppdagelse.

- Automatisk Bluetooth-oppdagelse krever nå at annonsert enhetsnavn **starter med Xzense** (`Xzense*`), i stedet for å godta den delte DSPS-UUID-en.
- Oppsettsveiviseren bruker samme navnefilter, også når den viser oppdagede enheter i listen.
- Manuell registrering med Bluetooth-adresse og PIN er beholdt for enheter som ikke annonserer navnet.
- Nye regresjonstester kontrollerer både Xzense-navnevarianter og at fremmede eller navnløse DSPS-enheter avvises.
- Ingen endringer i Bluetooth-tilkobling, oppdateringsintervaller, proxyvalg, kommandoer eller tilstandsbegrensninger.
- Dashboardkortet viser nå versjon **0.5.28.6**.

### Kjent begrensning

Automatisk oppdagelse krever at Bluetooth-navnet starter med `Xzense`. Enheter med annet navn eller uten annonsert navn må legges til manuelt. Eksisterende integrasjonsoppføringer slettes ikke.

**Verifikasjon:** Automatiske bygge- og regresjonstester. Ikke fysisk kontrollert på alle Xzense-modellvarianter.
