# Xzense 0.5.28.4

## English

**Breaking cleanup:** The active integration now uses only the `xzense` domain.

- The bundled dashboard card is served at **`/api/xzense/xzense-card.js`**. The former resource address is removed and **will no longer work**.
- If your Lovelace resource still uses the previous URL, open **Settings → Dashboards → Resources**, replace its URL with `/api/xzense/xzense-card.js?v=0.5.28.4`, and keep **JavaScript module** as the resource type. Remove any duplicate resources.
- Retired startup compatibility checks are removed. Only the current `xzense` integration is supported.
- The two persistent storage keys are now `xzense.timing_<entry_id>` and `xzense.cache_<entry_id>`. **Previously saved fire-session timing and cached diagnostic values are not migrated**; new tracking begins after upgrade.
- Bluetooth protocol, controller commands, and state-dependent controls remain unchanged. The battery display clamp and the dashboard button fix from prior releases remain intact.
- Regression/build validation checks the new URL, storage namespaces, version, and absence of the obsolete domain in the active Python integration.

**Version:** `0.5.28.4` · **Domain:** `xzense` · **Distribution:** GitHub Release/HACS.

**Validation:** Automated build checks only. Physical Home Assistant/controller operation after this change is not yet confirmed.

## Norsk

**Opprydding som bryter bakoverkompatibilitet:** Den aktive integrasjonen bruker nå bare domenet `xzense`.

- Dashboardkortet leveres på **`/api/xzense/xzense-card.js`**. Den tidligere ressursadressen er fjernet og **vil ikke fungere**.
- Hvis Lovelace-ressursen fortsatt bruker den gamle adressen, åpne **Innstillinger → Dashbord → Ressurser**, endre URL til `/api/xzense/xzense-card.js?v=0.5.28.4` og behold ressurstypen **JavaScript-modul**. Fjern eventuelle doble ressursoppføringer.
- Gamle kompatibilitetssperrer ved oppstart er fjernet. Bare den aktive `xzense`-integrasjonen støttes.
- Lagringsnøklene er endret til `xzense.timing_<entry_id>` og `xzense.cache_<entry_id>`. **Tidligere lagret fyringsvarighet/-historikk og bufrede diagnostikkverdier flyttes ikke**. Registrering starter på nytt etter oppgraderingen.
- Bluetooth-protokollen, kommandoene til kontrollpanelet og styringen etter driftstilstand er uendret. Batteribegrensningen og dashboardknapperettelsen fra tidligere versjoner er beholdt.
- Automatiske byggekontroller sjekker ny URL, lagringsnøkler, versjonsnummer og at gammelt domene ikke finnes i aktiv Python-kode.

**Versjon:** `0.5.28.4` · **Domene:** `xzense` · **Distribusjon:** GitHub Release/HACS.

**Verifikasjon:** Automatiske byggetester. Endringen er foreløpig ikke fysisk verifisert i Home Assistant og mot kontrollpanelet.
