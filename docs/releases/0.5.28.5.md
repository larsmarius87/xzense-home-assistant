# Xzense 0.5.28.5

## English

**Corrected public release for the domain and dashboard resource cleanup introduced in 0.5.28.4.** This version also updates the version displayed inside the dashboard card to match the integration.

- Only the `xzense` domain is used in the active integration.
- The dashboard JavaScript is served exclusively at **`/api/xzense/xzense-card.js`**. The previous resource URL is removed. Update **Settings → Dashboards → Resources** to `/api/xzense/xzense-card.js?v=0.5.28.5`, type **JavaScript module**. Remove any duplicate entries.
- The card's footer and browser console now identify version **0.5.28.5**.
- Old side-by-side integration compatibility code is removed.
- Storage keys for firing-session timing and cached diagnostics are now `xzense.timing_<entry_id>` and `xzense.cache_<entry_id>`. **Existing saved timing/history and cache from the earlier domain are not migrated.**
- The 0.5.28.3 dashboard button fix and 0.5.28.2 battery sensor cap remain.
- No change to BLE commands or control states.

**Compatibility:** This deliberately breaks old dashboard resource URLs. Update the resource manually after installing.

**Validation:** GitHub Actions tests and tagged source checks; not yet tested on a physical controller after this cleanup.

## Norsk

**Korrigert offentlig utgivelse av domene- og ressursoppryddingen fra 0.5.28.4.** Denne versjonen retter også versjonsnummeret som vises nederst i dashboardkortet, slik at det samsvarer med integrasjonen.

- Den aktive integrasjonen bruker bare domenet `xzense`.
- Dashboardfilen leveres utelukkende på **`/api/xzense/xzense-card.js`**. Tidligere ressursadresse er fjernet. Endre ressursen under **Innstillinger → Dashbord → Ressurser** til `/api/xzense/xzense-card.js?v=0.5.28.5`, type **JavaScript-modul**. Fjern eventuelle doble oppføringer.
- Nederst i dashboardkortet og i nettleserkonsollen står nå versjon **0.5.28.5**.
- Gammel kompatibilitetskode for parallelle integrasjoner er fjernet.
- Fyringshistorikk og diagnostikkcache lagres nå under `xzense.timing_<entry_id>` og `xzense.cache_<entry_id>`. **Tidligere lagrede tider og cache fra det gamle domenet blir ikke overført.**
- Rettelsen for dashboardknapper i 0.5.28.3 og begrensningen til 100 % batteri i 0.5.28.2 er beholdt.
- Ingen endringer i Bluetooth-kommandoer eller driftstilstandsstyring.

**Kompatibilitet:** Gamle dashboardressurser slutter bevisst å virke. Endre ressursadressen manuelt etter installasjon.

**Verifikasjon:** GitHub Actions og kontroll av publisert kildekode; ikke fysisk testet mot kontrollpanelet etter oppryddingen.
